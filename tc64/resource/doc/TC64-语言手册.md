# TC64 语言手册

> 本手册**只描述经过实测验证的内容**。凡未验证的语法一律不写，宁缺勿编。
> 版本：0.1.0（对应 `bin\tc.exe` SHA256 见 `build-info.txt`）

## 1. 五分钟上手

```
set PATH=D:\zhuo miam\tanchise\tc64\bin;%PATH%
cd 你的代码目录
tc hello.tc                     :: 生成 a.exe（与 gcc/mingw 一致）
tc hello.tc -o hello.exe
hello.exe
```

最小的完整程序：

```tc
module hello

import "tcrt/rt.tc"

fn main() -> i32:
    if !rtInit():
        return 1
    rtPrint("Hello, TC64!\n")
    return 0
```

**三个必须知道的规则**

1. 入口文件必须写 `module 名字`，且必须有 `fn main() -> i32`
2. `rtInit()` 必须在做任何 I/O 之前调用（初始化运行时）
3. `import` 路径由工具链自动解析（见第 5 节），写短路径即可

## 2. 两种写法，随便挑

同一门语言同时支持 **花括号/分号** 和 **缩进/Python 风格**，可以混写。

| 特性 | 传统写法 | 新写法 |
|---|---|---|
| 函数 | `fn f() -> i32 { ... }` | `fn f() -> i32:` + 缩进 |
| 函数别名 | `fn f()` | `def f()`（等价） |
| 语句结尾 | `let x: i32 = 1;` | `let x: i32 = 1` |
| 代码块 | `{ ... }` | 行尾 `:` + 缩进 |
| 注释 | `// 注释`、`/* 块 */` | `# 注释`（行首/行尾均可） |

**缩进块规则**（实测行为）：

- 父行**以冒号结尾**，下一行**缩进更深** → 开块（`INDENT`）
- 缩进**变浅** → 连续关块（`DEDENT`，可一次关多层）
- **空行与纯注释行不影响缩进判定**
- 括号内换行不算语句结束（跨行表达式、跨行调用天然安全）

```tc
fn classify(v: i32) -> i32:
    if v < 0:
        return 1
    else:
        if v == 0:
            return 2
        else:
            return 3
```

## 3. 变量与类型

```tc
let a: i32 = 10        # 不可变（赋值会报错 TC2001）
var b: i32 = 20        # 可变
var c = 30             # 类型可省：由初值推断
```

类型：`i8 i16 i32 i64 u8 u16 u32 u64 f32 f64 bool void`、指针 `*T`、
数组 `[N]T`、切片 `[]T`、结构体 / 枚举 / 联合。

**结构体**（数组字段可用，已实测 `sizeof(Holder)=24`）：

```tc
struct Holder:
    n: i32
    buf: [4]i32
    tail: i32
```

> 结构体的花括号写法同样有效；上面展示的是缩进写法。

## 4. 内建能力

| 名称 | 说明 |
|---|---|
| `rtInit()` | 初始化运行时，**必须最先调用** |
| `rtPrint(s)` / `rtPrintErr(s)` | 输出到 stdout / stderr（UTF-8） |
| `rtPrintI64(v)` | 打印 i64 |
| `sizeof(T)` / `sizeof(expr)` | 编译期求值 |
| `as` | 类型转换：`x as i64` |
| `read_gs(offset)` | 读 GS 段（PEB 等），编译器内建 |
| `syscall(编号, a1..aN)` | 直接系统调用 |
| `null` | 空指针 |

编译器产出的 exe **导入表为空** —— 不依赖任何系统 DLL，全部走系统调用。

## 5. import 与搜索路径

`import` 是**文本展开**（include-once），解析顺序：

1. 相对「发出 import 的那个文件」所在目录
2. `<root>\include`
3. `<root>\x86_64-w64-tcwin32\include`
4. `<root>\lib`
5. `<root>\x86_64-w64-tcwin32\lib`
6. `-I <目录>`（可重复）

`<root>` = 编译器所在目录的上一级 → **整个 TC64 目录可以搬到任意路径**。

```tc
import "tcrt/rt.tc"        # 运行时
import "libtccore.tc"      # 容器/字符串/映射（等价 mingw 的 -ltccore）
import "libtcgfx.tc"       # 像素画布与颜色
```

找不到文件时会明确报错（`TC5001`），并列出已尝试的目录。

## 6. 命令行

```
tc [选项] <source.tc> [选项]
```

| 选项 | 说明 |
|---|---|
| `-o <路径>` | 输出文件名（默认 `a.exe`） |
| `-gui` | 不弹控制台窗口（窗口程序） |
| `-console` | 弹控制台（默认） |
| `-I <目录>` | 追加 import 搜索目录 |

选项可以写在源文件**前面或后面**，第一个不以 `-` 开头的参数就是源文件。

## 7. 诊断

编译错误统一格式：

```
error[TC2001]: let 声明的变量不可赋值，请改用 var
  --> build\demo.tc:8:5
     |
   8 |     a = 2;
     |     ^
共 3 个错误。
```

| 编号 | 含义 |
|---|---|
| `TC1` | 命令行 / 用法错误 |
| `TC2` | 无法打开源文件 |
| `TC3` | 找不到入口函数 main |
| `TC4` | 无法写入输出文件 |
| `TC1001` | 语法错误 |
| `TC2001` | 语义错误（类型/赋值/未声明等） |
| `TC2002` | 全局符号重复定义 |
| `TC5001` | 找不到被导入的文件 |

成功时输出：`编译成功：N 个函数。`

## 8. 已知限制（不掩饰）

| 限制 | 后果 |
|---|---|
| `import` 是文本展开，**无模块命名空间** | 所有文件共享一个全局命名空间；同名顶层符号会冲突（现已报 `TC2002`，但不会自动隔离） |
| **无调试信息**（无行表 / 符号表） | 不能单步调试，只能靠 `rtPrint` 观察 |
| **无优化** | 直接发射，不做寄存器分配之外的优化 |
| **仅 x64 Windows** | 无跨平台后端 |
| **无标准库的完整覆盖** | 运行时只提供内存 / 文件 / 控制台 / 系统调用；格式化与容器在 `tclib\core` |
| 平台绑定未纳入工具链 | 当前没有窗口 / 输入 / 音频能力，画布只能输出到内存 |
| 函数重载、闭包、异常 | 未实现 |

## 9. 验证与重建

```cmd
tools\test.cmd        :: 自举不动点 + 7 项回归测试
tools\selfhost.cmd    :: 从引导器重新构建编译器（5 阶段，收敛检查）
tools\sync_tc64.cmd   :: 把新编译器同步进 TC64 并打印哈希
```

**判断编译器是不是自举产物**（详见 `build-info.txt`）：

```cmd
tc64\bin\tc.exe tcc\tc_main.tc -o build\_selfgen.exe
certutil -hashfile build\_selfgen.exe SHA256     :: 应与 tc64\bin\tc.exe 完全相同
```
